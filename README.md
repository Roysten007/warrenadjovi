# Portfolio Warren ADJOVI 🎬

> Monteur Vidéo & Motion Designer — Portfolio interactif et configurateur de tarifs.

## 🚀 Fonctionnalités

- **Configuration de Tarifs Interactive** : Calculateur en temps réel avec sélection de formats, volumes et options avec animations fluides.
- **Galerie de Réalisations** : Grille de vidéos verticales 9:16 avec aperçu vidéo au survol et lecteur vidéo modal.
- **Témoignages Défilants (Marquee)** : Carrousel infini de retours d'expérience clients.
- **Preuves Sociales WhatsApp** : Captures réelles et lecteur vidéo/vocal intégré.
- **Responsive & Dark Mode** : UI Obsidian Black (`#000000`) avec accents néon vert chartreuse (`#84cc16`).

## 🛠️ Stack Technique

- **Framework** : React 18 + TypeScript + Vite
- **Styles** : Tailwind CSS + CSS Keyframes Marquee
- **Icons** : React Icons (FontAwesome 6)
- **Animation** : Canvas Confetti + React Hooks

## 📦 Installation & Déploiement

```bash
# Installation des dépendances
bun install

# Lancement en mode développement
bun run dev

# Build pour la production
bun run build
```

## 🌐 Déploiement Vercel

Ce projet inclut un fichier `vercel.json` préconfiguré pour le déploiement automatique sur Vercel.
